# Ручное редактирование глав и свои ассеты

## 1. Где лежит сценарий

После извлечения:

```bat
.venv\Scripts\python.exe modmaker\extract_resources.py --only chapter_01
```

глава находится в `modmaker\extracted\TextAsset\101_chapter_01.json`.
Это обычный JSON в кодировке UTF-8. Редактируйте любым текстовым редактором
(VS Code, Notepad++). Проверяйте, что файл остаётся валидным JSON
(запятые, кавычки, скобки).

## 2. Структура главы

- `chapterId` — идентификатор, не меняйте.
- `chapterTitle` / `chapterTitle_en` — название, видно в игре.
- `startingNodeId` — узел, с которого начинается глава.
- `nodes[]` — узлы сюжета. У каждого:
  - `nodeId` — уникальный идентификатор;
  - `nextNodeId` — куда идти после последней строки (пусто = конец ветки);
  - `lines[]` — реплики по порядку.

Строка (`lines[]`):

| Поле | Что делает |
|---|---|
| `characterName` (+`_en`) | Имя говорящего, пусто = narration |
| `text` (+`_en`) | Текст реплики |
| `backgroundImage` | Фон (имя текстуры или PNG-файла, `""` = оставить, `"none"` = убрать) |
| `characterSprite` | Спрайт персонажа (`""` = оставить прежний, `"none"` = скрыть) |
| `characterPosition` | `center`, `left`, `right`, `close`, `far` |
| `musicClip` | Музыка (`"none"` = остановить) |
| `sfxClip` | Звук: `имя`, `имя:громкость`, `имя:громкость:loop`; `"stop"` = остановить loop |
| `voiceClip` | Озвучка строки |
| `overlayAlpha` | Затемнение: `-1` = нет, `0..1` = степень |
| `emotion` | Поле есть, игрой сейчас не используется |
| `requiredVariables` | Строка видна, только если переменная выставлена |
| `choices` | Выборы (см. ниже) |

Выбор (`choices[]`):

| Поле | Что делает |
|---|---|
| `choiceText` (+`_en`) | Текст варианта |
| `targetNodeId` | Узел перехода |
| `setVariable` + `modifyValue` | Выставить переменную (обычно `1`) |
| `requiredVariables` | Выбор доступен, только если переменная выставлена |
| `lockedText` (+`_en`) | Текст закрытого варианта (показывается вместо `choiceText`) |

Переменные — целые числа. Несколько условий через запятую:
`"went_to_cafeteria_ch1,hugged_milly_twice"`. Переменные живут между
перепрохождениями (например, выбор главы 1 влияет на главу 2).

## 3. Типовые правки

- Поменять текст: правите `text` / `text_en` у нужной строки.
- Скрыть персонажа перед narration: поставьте `"characterSprite": "none"`.
- Сменить фон: поставьте существующее имя (`zoo`, `cafe`, `room_day`, ...).
  Полный список имён — в `objects_list.txt` после извлечения.
- Добавить узел: скопируйте любой узел, дайте новый `nodeId`, сошлитесь
  на него через `nextNodeId` или `targetNodeId` выбора.

## 4. Возврат правок в игру

Сначала проверка без записи (из корня игры):

```bat
.venv\Scripts\python.exe modmaker\repack_resources.py --srcdir modmaker\extracted --dry-run
```

Если diff ожидаемый — запись:

```bat
.venv\Scripts\python.exe modmaker\repack_resources.py --srcdir modmaker\extracted
```

Оригинал сохраняется в `LED HEARTS_Data\resources.assets.bak` (один раз).

## 5. Свои ассеты: куда кидать и в каком формате

Игра сначала ищет ассет в `resources.assets`, а если не находит —
загружает внешний файл **из корня игры** (рядом с `LED HEARTS.exe`).

### Фоны и спрайты — PNG в корне игры

- Формат: обычный PNG, любой размер (для фонов желательно 1920×1080).
- Имя файла = имя в сценарии. Пример: файл `my_room.png` в корне игры
  используется строкой `"backgroundImage": "my_room"`.
- То же для персонажей: `my_hero.png` + `"characterSprite": "my_hero"`.
- Не кладите их в подпапки (например, в `modmaker/`) — загрузчик смотрит
  строго в корень игры.

### Звуки — WAV в корне игры

- Формат: WAV, PCM 16-bit, 44100 Гц, моно или стерео.
  Именно такой WAV игра конвертирует через `WavBytesToAudioClip`.
- Имя файла = имя в сценарии без расширения. Пример: `my_jingle.wav`
  используется как `"sfxClip": "my_jingle:0.9"` (громкость 0–1).
- Работает во всех трёх полях: `sfxClip`, `voiceClip`, `musicClip`.
- Пример в комплекте: `modmaker\mod_demo_jingle.wav`
  (скрипт `mod_demo_node.py` сам копирует его в корень).
