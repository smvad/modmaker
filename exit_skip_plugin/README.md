# Exit Skip — пропуск экрана выхода «ТАК И ЗНАЛ»

BepInEx-плагин для LED HEARTS: позволяет пропустить непропускаемый экран,
который появляется при выходе из игры
(капча «ПРОВЕРКА БЕЗОПАСНОСТИ» → «Я не робот» → хоррор «ТАК И ЗНАЛ»).

## Как работает

Пока видна капча выхода или хоррор-оверлей, **любая клавиша клавиатуры
или любая кнопка мыши** (левая/правая/средняя/боковые) сразу закрывает
экран и выходит из игры. Первые ~1 с после появления экрана нажатия
игнорируются, а нажатие, которым экран открыли (клик по «Я не робот»),
не засчитывается — иначе экран пропускался бы сам. Клавиши-переключатели
(Caps/Num/Scroll Lock) пропуском не считаются.

После первого скипа кнопка «Выход» в меню выходит из игры сразу,
не показывая капчу повторно. Без открытых экранов выхода игра работает
как обычно — мод ничего не перехватывает.

Отключение без удаления: `BepInEx/config/ledhearts.exit.skip.cfg`,
`General/Enabled = false`.

## Установка

Нужен BepInEx 6 (Unity.IL2CPP) в корне игры и один запуск игры
(чтобы сгенерировался `BepInEx/interop/`). Далее из корня игры:

```bat
dotnet build modmaker\exit_skip_plugin\ExitSkip.csproj -c Release
copy modmaker\exit_skip_plugin\bin\Release\net6.0\ExitSkip.dll BepInEx\plugins\
```

## Проверка

1. В `BepInEx\LogOutput.log` после запуска: `Exit Skip loaded, patches: 3/3`,
   без ошибок.
2. Обычная игра без открытых экранов выхода работает как раньше.
3. Нажать «Выход» → отметить «Я не робот» → на экране «ТАК И ЗНАЛ»
   нажать любую клавишу или кнопку мыши → игра сразу закрывается
   (в логе: `ExitSkip: skip pressed ..., quitting`).

## Удаление

Удалить `BepInEx\plugins\ExitSkip.dll` (и при желании
`BepInEx/config/ledhearts.exit.skip.cfg`). Сейвы и файлы игры не трогаются.
